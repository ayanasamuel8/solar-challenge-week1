# Notebooks Directory

This directory contains Jupyter notebooks for data analysis, visualization, and model development.

## Structure

- `exploratory/`: Exploratory Data Analysis (EDA) notebooks
- `modeling/`: Model development and evaluation notebooks
- `visualization/`: Data visualization notebooks

## Usage

1. Ensure you have activated the virtual environment
2. Launch Jupyter notebook:

```bash
jupyter notebook
```

3. Navigate to the desired notebook

## Best Practices

1. Keep notebooks organized and well-documented
2. Use markdown cells to explain your analysis
3. Clean up output before committing
4. Move reusable code to the `src` directory
